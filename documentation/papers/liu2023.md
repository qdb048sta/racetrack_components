## What it models

This is a tire structural-dynamics dissertation. It does not supply a complete
car handling model, a lateral racing-control tire law, or an MPC algorithm.
Its contributions concern vibration, road contact, tire uniformity and uncertainty.

## Physical formulation and numerical solution

The ring is supported by radial, circumferential and axial elastic/damping
elements. Hamilton's principle is used to derive the governing equations (2.10),
including elastic strain energy, inertia, inflation pressure and external forces.
The in-plane equations are (2.16-2.17); out-of-plane bending/torsion are
(2.18-2.19). This is much more than the scalar relation `Fy=C*alpha`.

For the nonrotating in-plane special case, substituting sinusoidal modes gives

\[
\det(K_n-\omega^2 M)=0,\qquad M=\rho A I.
\]

Eq. 2.20 gives the two-by-two stiffness matrix. Defining
`a=EA/R^2`, `b=EI/R^4`, `p=p0*width/R`, its entries are

\[
K_{11}=a+bn^4+pn^2+k_u,\quad
K_{12}=K_{21}=-an-bn^3-pn,
\]
\[
K_{22}=an^2+bn^2+pn^2+k_v.
\]

`ModalRing.modes()` solves this generalized symmetric eigenproblem. For a
prescribed modal force, `ModalRing.integrate()` solves
`M*qdd+C*qd+K*q=f(t)` with SciPy's implicit Radau integrator. The damping
matrix is an explicit illustrative diagonal sidewall-damping choice. This is a
nonrotating in-plane reduction, not the entire rotating 3D model.

The relaxation law is an actual tire-force ODE:

\[
\sigma_t\dot F_{cx}+|V_r|F_{cx}=|V_r|F_{cxn}.
\]

For held speed/nominal force, `relaxation_step()` uses its exact exponential
solution. At zero rolling speed the force state remains unchanged according to
this equation. Full adhesion makes the relaxation length equal to half the
contact length in the source's model (pp. 43-44); the code requires that length
as an input instead of inventing a contact patch from the racecourse CSV.

`RigidRing` implements all five second-order equations (3.110-3.114), converted
to ten first-order states. Its inputs are signed contact force, contact moment,
rim load/torque and prescribed rim longitudinal motion. The force sign convention
is explicit: positive z is downward, so the normal road reaction is usually
negative. The runner applies a prescribed vertical force pulse about static
equilibrium, with carrier rotation zero. It is not a reconstructed cleat experiment.

In the full thesis algorithm, flexible-ring contact supplies those forces, then
the rigid-ring integrator returns positions/speeds for the next contact solve.
That nonlinear contact module is **not implemented in this branch**. Hence the
rigid ODE and modal ring are tested submodels, not a completed coupled simulation.

## Uncertainty algorithm

Chapter 5 expands outputs in orthogonal polynomials of standardized random
variables. Collocation runs the deterministic tire model at selected parameter
samples, builds a design matrix `A`, and fits coefficients from `A*c=G`.
`LegendrePCM` implements the independent-uniform-input member of this family.
It uses an SVD least-squares solve instead of explicitly forming the normal-equation
inverse printed in Eq. 5.139. It checks rank and rejects insufficient samples.

The demonstration varies radial foundation stiffness uniformly by +/-10%, fits
a cubic surrogate for one natural frequency, and checks it on held-out points.
It calculates mean/variance using Legendre orthogonality. It does not implement
all Askey distributions, geometric defects, measured radial-force variation or
the dissertation's full parameter-identification procedure.

## Why this cannot simply replace the current tire

The existing stateless tire interface accepts slip and load and returns forces.
Liu's model needs deformation/rim states, structural parameters, contact geometry,
terrain height under the footprint and an integration history. It also does not
by itself provide the racing model's lateral `Fy(alpha)` law.

A future full-car integration would need to add ring/suspension states to the
plant, implement the flexible contact solver and identify parameters, decide how
handling forces coexist with structural/contact forces, and expose matching or
deliberately reduced prediction dynamics to MPC. Treating `Fcx` relaxation as
one extra state is possible, but it is not the whole rigid-flexible model.
The current `FlatSurface`/CSV is insufficient to specify a measured cleat input.

## Code, run and validation

```bash
python -m pip install -r requirements-driving.txt
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python run_paper_liu.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m unittest discover -s tests -p 'test_paper_liu.py' -v
```

Core code: `tracklab/paper_models/liu2023.py`; composition:
`run_paper_liu.py`. Outputs are modal time series, relaxation/rigid responses,
frequency table and summary. The parameter dataclasses explicitly contain
illustrative SI values, not fitted coefficients from the thesis's experimental tire.

Five tests check generalized eigenpair residuals, an analytic undamped modal
solution, the exact relaxation time constant, static ring/rim force balance and
polynomial recovery/statistics. The sample mode-2 frequencies are about 52.32 Hz
and 753.49 Hz for these illustrative parameters, not experimental-validation
claims. The held-out cubic PCM error is about `2e-7 Hz` in this one-parameter
example. The 31 baseline road/Python-driving tests pass.

No MPC, car trajectory or full coupled contact result is claimed for this branch.
